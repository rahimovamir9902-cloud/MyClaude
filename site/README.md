# ДомПлюс — сайт агентства недвижимости

Готовый **статический сайт** для риелторского агентства: продажа и аренда
квартир и домов. Написан на чистом HTML / CSS / JavaScript — **без сборки и
без бэкенда**, открывается прямо в браузере.

## Что внутри

| Раздел | Описание |
|---|---|
| 🔎 **Каталог квартир и домов** | Карточки объектов с ценой, параметрами, фото-плейсхолдером и характеристиками. Фильтры по типу (квартира/дом), сделке (покупка/аренда), городу + поиск. |
| 🎨 **Дизайн** | Современный адаптивный интерфейс: hero-блок, преимущества, анимации карточек, мобильное меню. Все изображения — встроенные SVG (не зависят от интернета). |
| 📍 **Адреса и филиалы** | Офисы в Москве, Санкт-Петербурге, Казани и Екатеринбурге с адресами, телефонами и часами работы. |
| 🛒 **Покупки** | Кнопка «Купить» / «Оставить заявку», модальное окно заявки, избранное (♥) с сохранением в браузере, шаги сделки. |
| ⭐ **Отзывы** | Отзывы клиентов со звёздами + форма добавления собственного отзыва (сохраняется локально). |

## Как открыть

Просто откройте `index.html` в браузере. Либо запустите локальный сервер:

```bash
cd site
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Структура

```
site/
├── index.html        # разметка всех разделов
├── css/styles.css    # оформление и адаптив
└── js/
    ├── data.js       # данные: объекты, филиалы, стартовые отзывы
    └── app.js        # каталог, фильтры, избранное, заявки, отзывы
```

## Хранение данных

Избранное, отзывы и заявки сохраняются в `localStorage` браузера, поэтому
сайт полностью функционален без сервера. Для боевого проекта данные из
`data.js` заменяются на загрузку с API, а форма заявки — на отправку на бэкенд.
