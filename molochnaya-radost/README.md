# Молочная Радость — демо-приложение FMCG

Демонстрационное веб-приложение для молочного бренда премиум-класса
**«Молочная Радость»**. Одностраничный витринный магазин с каталогом
продукции и рабочей корзиной.

## Дизайн

- **Стиль:** премиум, единый тёмно-синий (navy) фирменный мир.
- **Палитра:** глубокий тёмно-синий фон, тёплый крем для текста,
  тонкие золотые линии для премиальности.
- **Кнопки:** акцентный **красный** (`#E1232E`) — все действия
  (CTA, «в корзину», оформление заказа).
- **Типографика:** дисплейный serif для бренда и заголовков,
  системный sans для интерфейса. Внешние шрифты не подключаются.

## Что внутри

- Каталог из 12 продуктов (молоко, кисломолочное, творог и сыр, масло)
  с фильтром по категориям.
- Иллюстрации упаковки нарисованы инлайн-SVG (карton / бутылка / стакан /
  брусок) — без внешних картинок, работает офлайн.
- Рабочая **корзина-шторка**: добавление, изменение количества,
  подсчёт суммы, оформление заказа с уведомлением.
- Адаптивная вёрстка (десктоп / планшет / телефон), доступность
  (фокус-стили, `aria`, `prefers-reduced-motion`).

## Запуск

Всё в одном файле — зависимостей нет.

```bash
# просто откройте в браузере
open molochnaya-radost/index.html      # macOS
xdg-open molochnaya-radost/index.html  # Linux

# или локальный сервер
python3 -m http.server 8080 -d molochnaya-radost
# → http://localhost:8080
```
